Design Tokens Used

  • --color-primary - Background color
  • --color-text-inverse - Text color
  • --border-radius-xl - Border radius
  • --duration-normal - Transition duration
  • --easing-smooth - Transition easing
  • --font-weight-semibold - Font weight
  • --spacing-3, --spacing-4 - Padding
  • --opacity-50 - Disabled state
